# Maroon 5 Fan Website

## Description
This project is a responsive, basic web page dedicated to the band Maroon 5, built strictly using semantic HTML5 and custom CSS (Flexbox and Grid). The design philosophy and aesthetic are inspired by the "Ruta del Agua" web template, ensuring a clean, modern layout tailored for three distinct responsive breakpoints (Desktop, Tablet, and Mobile).
